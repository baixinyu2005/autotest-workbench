AutoTest Workbench 使用说明
================================

一、运行

1. 将压缩包完整解压到 D 盘或 E 盘，例如：
   D:\AutoTestWorkbench

2. 双击 AutoTestWorkbench.exe 启动。
   不要只复制 exe，必须保留 _internal 文件夹和 demo 文件夹。

3. 第一次启动会在非 C 盘创建数据目录，默认：
   D:\AutoTestWorkbenchData

   如果 Windows 提示“未知发布者”，点击“更多信息”->“仍要运行”。
   这是未购买代码签名证书的自制程序，不是病毒。

4. 本程序需要本机安装 Microsoft Edge 或 Google Chrome。
   Windows 10/11 通常自带 Edge，不需要安装 Python 或 Node。

二、使用

1. 点击左侧“测试向导”，按 1 → 2 → 3 操作。
2. 第 1 步导入需规：选择 Excel，或点击“扫描文件夹”；
   程序会自动识别验收用例、功能需求、功能清单、标准用例，
   并自动提取测试账号和权限。
3. 第 2 步填写软件网址，选择测试账号；
   用户名/密码会自动填充，也可以手动改。
4. 第 3 步点击“开始测试”；
   日志和进度显示在“测试执行”页。
5. 测试完成后，在“测试报告”中打开 HTML/Excel 报告。
6. 如果功能清单没有步骤，可以在导入页导出可编辑计划，
   或双击需求行，在桌面程序中编辑步骤和选择器。

大文件说明：
- 上千条需规也可以导入；
- 界面只预览前 1500 条，项目和报告保留全部数据。

三、重要说明

1. 没有配置页面步骤的需求，报告会标记为“未配置”，
   不会算作通过。这是为了避免伪造测试结果。

2. 送审单位的 Excel 可能只有功能清单，没有操作步骤和预期结果，
   这时只能生成用例骨架。要真实测试，需要：
   - 连接能访问 192.168.1.10:8080 的校园/公司网络或 VPN；
   - 提供测试账号；
   - 根据真实页面补充菜单、按钮、字段选择器和断言。

3. 默认数据目录不在 C 盘，可在“设置”中修改。
   测试日志、截图、下载、缓存、临时文件、报告都在数据目录内。

4. 本工具只用于本机测试，不连接云端，不上传测试数据。

四、演示文件

demo\volunteer_demo_plan.xlsx
    本机志愿填报系统的演示计划，可用于验证自动化引擎。

demo\自动化测试用例模板.xlsx
    标准用例 Excel 模板，填写步骤、目标和预期后可执行。
